Run this command in your terminal to export the Supabase database:

cd ~/Desktop/Claude\ Code\ Apps/Supply\ Chain\ app/migration
mkdir -p exports

PGPASSWORD=tfy3MrsCfcWsP4pP pg_dump \
  --host=db.pxwtdaqhwzweedflwora.supabase.co \
  --port=5432 \
  --username=postgres \
  --dbname=postgres \
  --schema=public \
  --no-owner \
  --no-privileges \
  --no-tablespaces \
  --no-unlogged-table-data \
  --file=exports/supabase_full_export.sql

After running this, you should see a file created at:
migration/exports/supabase_full_export.sql

To verify the export worked, check the file size:
ls -lh exports/supabase_full_export.sql

The file should be several MB in size and contain:
- CREATE TYPE statements for your enums
- CREATE TABLE statements
- INSERT statements with your data
